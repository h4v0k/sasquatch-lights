Light Tester

Connects to the Mustang's light controllers and sends the documented commands. If a box changes color, its protocol is confirmed.

Bluetooth isn't available in this browser. Open this page in Chrome on the Android phone. iPhone Safari can't do Web Bluetooth; on iPhone, the free Bluefy browser can.

How to run it

  1. Close the OPT7 PLUS and HappyLighting apps (a box only takes one connection).
  2. Tap Connect a box and pick it from the list. Repeat for each box.
  3. Tap Run test. It goes red, green, blue, white, then off.
  4. Nothing happened? Pick the next protocol in the list and run the test again.
  5. Tap Copy log and paste it to Claude.
